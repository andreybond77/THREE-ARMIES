⚔️🏰 ТРИ АРМИИ 🏰⚔️
Битва полководцев

«Три армии» — логическая пошаговая стратегия для двух игроков (человек против компьютера), сочетающая классические шашечные механики и уникальную систему трёх цветных армий, образующих замкнутый цикл «хищник-жертва».

У каждого игрока есть армии трёх цветов: 🔴 красные-Архи, 🟢 зелёные-Орки и 🔵 синие-Ирмы шашки. Они могут ходить во все стороны, а успех зависит не только от позиции, но и от правильного выбора армии для атаки.

📜 ПРАВИЛА ИГРЫ

  • ♟️ Шашки ходят: ↑ ↓ ← → (1 клетка)
  • ⚔️ Бьют по диагонали ↗ ↖ ↘ ↙ (1 клетка)
  • 🔄 Одинаковые цвета по диагонали → могут меняться местами
  • 🏆 За съеденную шашку +1 очко
  • ⚡ Игрок с большим количеством очков побеждает

🔄 ЦИКЛ «ХИЩНИК-ЖЕРТВА»

🔴 Арх
→ бьет 🟢 Орка
→
🟢 Орк
→ бьет 🔵 Ирма
→
🔵 Ирм
→ бьет 🔴 Арха

⚠️ Атаковать можно только те шашки, которые уязвимы для вашего цвета!

🏆 Вперёд, доблестный полководец! Тебя ждёт слава и победа в грядущих битвах.

Твоё имя будет выбито на граните олимпийской славы.
